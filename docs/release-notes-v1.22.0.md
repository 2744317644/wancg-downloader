## 全流程 UI/功能走查 + 体验美化

这版在 iOS 26.2 模拟器上把整个 App 的界面和主要流程自动跑了一遍（新增全流程 UI 走查测试），并针对发现的问题做了修复和一轮视觉统一。

### 全流程走查覆盖

首页（含下拉刷新）→ 搜索 → 分类（筛选/自动加载）→ 详情 → 阅读器 → 下载页（真实解析一部作品）→ 收藏 → 文件 → 历史 → 设置（含深色模式切换）；浅色 + 深色两轮，逐屏截图并检查无障碍树。

### 修复

- **下载页解析后键盘不收起**：点「解析作品」后键盘会一直挡住底部页签栏，导致必须手动收起键盘才能切页；现在解析时主动收起键盘，并给键盘加了「完成」按钮。

### UI 美化

- **统一全 App 背景**：首页 / 分类 / 详情 / 下载 / 收藏 / 空状态统一使用同一套渐变背景，不再出现有的页面纯灰、有的页面渐变。
- **首页骨架屏**：首屏加载由居中菊花改为 9 张骨架卡占位，图片回来时自然填充；栏目头显示「N 部」，并扩大「更多」的可点击区域。
- **详情页按钮层级**：「开始阅读」改为强调色主按钮，「下载 ZIP + PDF」改为次级按钮；「标签」「看过这本的人也看了」统一章节标题样式；「复制标题」点击区域增大。
- **下载页**：新增「粘贴」按钮，一键从剪贴板填入作品链接。
- **设置页**：「关于」区域新增构建号和「查看最新版本」链接。
- **细节**：收藏/推荐卡片统一按压缩放反馈；文件/历史/收藏空状态与全局背景一致。

### 验证

- 新增 `AppWalkthroughUITests`：全流程浅色 + 深色走查、真实解析、搜索、阅读器开关、设置切换；
- 原有分类页自动化回归（自动加载、筛选、详情、阅读器、底栏断言）继续通过；
- 两个测试均在 **iOS 26.2 / iPhone 17 Pro** 模拟器通过，Release 编译 + 代理/解析 smoke test 通过。
