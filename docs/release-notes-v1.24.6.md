## 阅读器按钮下移到灵动岛底部

上一版把关闭 / 页数 / 刷新按钮的顶部对齐到了灵动岛顶部，位置偏高。这版改为：

- 三个悬浮按钮的**顶部与灵动岛底部持平**（顶部 padding 48pt，左右 24pt）；
- 内容仍全屏、切换沉浸不位移，单击/左缘返回/进度 HUD/页码条不变；
- UI 测试同步改为断言按钮 `minY` 在 30–60pt 之间（iPhone 17 Pro 屏幕上灵动岛底部约 48pt）。

### 验证

- iOS 26.2 完整全流程 UI 测试通过；
- iOS 18.x 分类页回归通过；
- 版本 **1.24.6**（build 268）。
