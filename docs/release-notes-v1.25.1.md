## 阅读器底部页数 HUD 跟随沉浸模式隐藏

- 之前底部「0% · 共 197P」的滚动页数 HUD 和顶部按钮不是同一个显隐状态，可能一直显示/残留；
- 现在底部页数 HUD 和顶部「关闭 / 页数 / 刷新」使用同一个 `chromeHidden`：
  - 点击页面隐藏沉浸 chrome 时，底部页数 HUD 一起淡出；
  - 再点一下恢复时一起出现；
- HUD 仍保留滚动时短暂出现、1.5 秒后淡出的行为；
- 顶部页数胶囊仍显示总页数，不影响查看总页数。
