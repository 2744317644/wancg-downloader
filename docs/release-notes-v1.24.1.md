## 详情页背景优化 + 阅读器左缘返回手势

### 详情页

- 上一版的“全宽模糊封面”会糊到标题和元信息，观感偏脏；这版改成**封面同色柔光晕**：
  - 模糊图只围绕左侧封面缩略图，用径向遮罩渐隐；
  - 标题、分类、页数、上传者等文字区域保持干净背景；
  - 保留加载后的淡入，加载失败时不影响原布局。

### 阅读器

- 新增**左缘右滑返回**：从屏幕左侧边缘向右滑即可关闭阅读器（和系统返回手势一致），不再只能点左上角关闭。
  - 触发条件：起点在左边缘 32pt 内、横向位移 > 90pt，且横向位移大于纵向，避免和滚动冲突。
