## 修复分类页「必须点加载更多」和底部末行空位

上一版把触底加载哨兵放在了**非懒加载**的外层 `VStack` 里：它在页面出现时只触发一次（所以会自动加载一页），之后无论怎么滑都不会再触发，用户只能点底部的「加载更多」按钮。

这版改了触发方式：

- 加载改由 `LazyVGrid` 中**最后几行卡片的 `onAppear`** 触发——只有用户真的把最后几行滑进渲染范围时才会加载，并且每追加一页都会重新武装，滑到底部就会自动继续加载；
- **提前 9 部（约 3 行）预取下一页**，下一页通常在用户看到列表末尾之前就已到达，所以最后一行不会再停在只剩 1 个封面的状态，而是被新一页的封面填满；
- 底部的「加载更多」按钮保留为兜底/手动重试入口；
- 上一版的请求节流、作品去重、筛选结果缓存、封面卡 `Equatable`、缩略图后台编码等性能修复全部保留。

### 验证

模拟器 UI 测试**完全不点击「加载更多」按钮**，只用滑动连续触发自动加载：已加载作品数 100 → 120 → 160 → 180，全程无加载失败；下拉刷新正常；Release 编译与代理/解析 smoke test 通过。
