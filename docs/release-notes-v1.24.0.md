## 阅读器沉浸模式、下载仪表盘、详情页封面氛围

这版把上一轮说的三个 UI 方向做完了。

### 阅读器：沉浸模式

- **单击页面隐藏/恢复导航栏、状态栏和工具栏**，图片占满整屏；再单击恢复。
- 右缘的页码拖动条增大到 32pt，并加入 6pt 触发阈值，减少“点一下右边就跳页”的误触。
- 保留滚动进度 HUD（「37% · 共 126P」，滚动时出现、1.5 秒后淡出）。

### 下载页：更完整的任务仪表盘

- 新增**最近下载**卡片：显示最近 3 个 ZIP/PDF，含文件大小、修改时间、分享按钮；
- 「全部文件」一键跳到文件页；
- 下载 tab 增加**角标**：进行中任务计 1，加上排队数量，切到别的 tab 也能看到还有任务在跑/排队。

### 详情页：封面氛围背景

- 用作品封面生成**模糊渐隐 hero 背景**（opacity 0.30、28pt 模糊、底部渐隐），不改变原 header 布局与可读性，给详情页增加层次感；
- 封面加载完成时淡入，失败则保持原背景。

- iOS 26.2 完整全流程 UI 测试通过；
- 最旧 iOS（18.x）分类页回归通过。
