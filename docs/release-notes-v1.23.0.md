## 主线程零阻塞、下载/阅读体验增强、双 iOS 版本 CI

这版把上一轮审计剩下的四个后续项做完了。

### 稳定性

- **本地代理改为懒加载**：代理启动需要等 listener 就绪（最长 5 秒），之前会在 App 启动、回前台、阅读器重载、设置切换时阻塞主线程；现在改到后台线程按需启动，回前台重建代理也在后台执行，UI 不再有卡顿窗口。
- 代理启动失败后的恢复路径也改到后台线程，不再阻塞界面。

### 下载体验

- **下载进度/Live Activity 更新节流**：网络分块与 PDF 逐页进度不再每次都刷新 UI/灵动岛（进度 UI ≤10 次/秒、Live Activity ≤2 次/秒、PDF ≤6.7 次/秒），降低主线程与灵动岛刷新压力。
- **下载队列卡片**：下载页会显示排队的作品、数量，并支持逐个取消排队（此前只能看到“已加入队列”状态文字）。

### 阅读体验

- **阅读进度 HUD**：阅读器滚动时底部浮出「37% · 共 126P」胶囊，1.5 秒后自动淡出；百分比来自真实滚动偏移，页面高度不一致也准确。
- 阅读器继续使用全屏 cover + 深色导航栏（返回时底栏已在）。

### 详情页

- **标签折叠**：默认展示前 8 个标签，提供「展开全部 N 个标签 / 收起标签」；标签点击区域统一到 44pt。

### CI

- UI 测试在 main 的 `ios/**` 改动时自动运行（上一版已加），并新增 **最旧可用 iOS runtime（当前 18.x）** 的并行分类页回归 job，覆盖部署目标 iOS 17/18 的兼容性；最新 runtime job 继续跑完整全流程测试。

### 验证

- iOS 26.2 全流程走查 + 分类页回归通过；iOS 18.x 分类页回归通过；Release 编译 + 代理/解析 smoke test 通过。
