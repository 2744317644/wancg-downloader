## Windows WinUI 3 客户端 v1.0.6

### 下载“突然停掉”的修复与诊断

- 之前网络请求超时会被当成“用户取消”，队列显示已取消，看起来像下载莫名其妙停掉；
- 现在区分**手动停止**与**网络超时**，超时会明确显示「网络请求超时或被中断」并给出检查提示；
- HttpClient 单次请求超时从 120 秒降到 45 秒，避免首张图片卡住两分钟；
- 下载期间保持系统唤醒（`SetThreadExecutionState`，防止长时间下载时系统进入睡眠/待机）；
- 新增本地日志：
  `%LOCALAPPDATA%\WnacgDownloader\logs\app.log`
  记录启动、下载开始/完成/超时/失败和未处理异常；
- XAML 未处理异常会先写入日志并尽量保持窗口不退出。

### 安装版

- `WnacgDownloader-Setup-1.0.6.exe`
- 覆盖安装即可，不需要卸载旧版。

> 如果仍然出现窗口直接消失，请把 `app.log` 最后 50 行发我，里面会记录具体异常。
