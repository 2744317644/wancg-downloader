## 修复自定义排除标签不生效

之前排除标签只做「标题包含标签关键词」匹配，标签没有出现在标题里时就不会被排除，所以看起来没生效。

### 现在的做法

- 新增 `ExcludedTagIndex`：把排除标签解析为站点真实的标签页
  `/albums-index-tag-<tag>.html`；
- 从标签页读取作品 ID 集合，翻页直到覆盖当前列表最旧作品日期（最多每次 8 页），
  用 **作品 ID 精确匹配** 是否属于该标签；
- 如果标签页索引尚未覆盖到某作品，仍按标题关键词回退，不会漏掉旧逻辑；
- 只在存在排除标签时才请求标签页，普通浏览不增加请求；
- 标签点击现在优先进入站点的标签页（而不是搜索页），标签搜索结果更准确。

### 应用范围

- 首页、分类、搜索结果、标签搜索结果都会应用；
- 排除标签管理入口不变：筛选条 / 设置 → 内容 / 详情页长按标签。
