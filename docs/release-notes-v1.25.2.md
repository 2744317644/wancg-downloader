## 首页修复：單行本标题与移除「最新上架」

### 單行本标题变成日期 + 张数

站点把單行本卡片的标题类名改成了 `class="txtA hei"`。旧解析只匹配 `class="txtA"`，标题匹配失败后又退回到卡片里的 `<span class="info">`，于是把「2026-11-07, 106張圖片」当成了标题。

修复：

- 标题匹配改为 `class="txtA[^"]*"`，兼容 `txtA hei` 等额外 class；
- 保留兜底，但改为用封面图 `alt`，不再回退到日期/图片数 info；
- 同人志、單行本、雜誌·短篇等栏目标题恢复正常。

### 移除「最新上架」

首页解析时直接跳过标题为 **「最新上架」**（以及桌面版的「最新更新」）的栏目；App 首页只保留同人志、單行本、雜誌·短篇。

### 验证

- 用真实 iPhone UA 首页 HTML 核对：單行本卡片标题为正常作品名（不再是日期 + 张数）；
- iOS 26.2 全流程 UI 测试 + 首页解析 smoke test 通过；
- 版本 **1.25.2**（build 271）。
