## 阅读器顶部按钮与灵动岛齐平

上一版把关闭 / 页数 / 刷新三个悬浮按钮移到了屏幕顶部两角，但它们仍在安全区下方，视觉上比灵动岛低一截。

这版修正：

- 给阅读器的悬浮 chrome 加上 `.ignoresSafeArea(edges: .top)`，让按钮进入状态栏/灵动岛所在的那一行；
- 顶部 padding 10pt、左右 24pt，避免灵动岛和屏幕圆角；
- XCUITest 实测（iPhone 17 Pro，屏幕 402×874pt）：
  - 关闭按钮 frame `x=23.75, y=9.75, 40.5×40.5`；
  - 与灵动岛同一行，不再位于安全区下方；
- 新增 UI 回归断言：按钮 `minY < 24`，防止以后再次掉下去。

其他行为不变：单击切换沉浸、左缘右滑返回、滚动进度 HUD、右缘页码条；内容仍全屏显示，切换时不会位移。
