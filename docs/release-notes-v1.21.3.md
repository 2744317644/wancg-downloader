## 让分类页的自动加载更跟手、偶发失败自动恢复

上一版滑到底已经能自动加载，但仍有两个体验缺口：

1. 有时追加一页后，要再手动滑一下（甚至以为卡住）才会继续加载；
2. 网络偶发失败（含站点 429）会停在“加载失败”，需要手动点刷新才能恢复。

这版改进：

- **网格内懒哨兵**：在 `LazyVGrid` 内部放一个只会随滚动进入渲染范围的哨兵，每加载一页就换一个 identity 重新武装；追加内容后它会被推到新位置，下次滑到末尾会再次触发，避免“必须再划一下”的停滞感；
- **预取距离从 3 行加大到 4 行**（提前 12 部），配合最后几行的 `onAppear` 双保险，下一页会更早到位，末行也更容易被填满；
- **失败自动恢复**：加载失败后 2.5 秒自动静默重试，最多 2 次，单次网络抖动会自愈，不必点刷新；
- 请求最小间隔从 1.1 秒降到 0.7 秒，滑动触发后响应更快，同时仍避免连续请求造成 429。

### 验证

模拟器 UI 测试不点任何按钮，仅滑动触发自动加载：已加载数 100 → 120 → 160 → 180，无失败；下拉刷新正常；Release 编译 + 代理/解析 smoke test 通过。
