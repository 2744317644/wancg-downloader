## 搜索/标签搜索筛选生效 + 排除标签

### 搜索和标签搜索也走筛选

- 之前搜索结果页传了 `appliesLanguageFilter: false`，只显示「屏蔽 AI」不显示语言选项；
- 现在搜索页和标签搜索页都显示完整的「全部 / 翻译 / 日语 / 屏蔽 AI / 排除标签」筛选条；
- 语言筛选、屏蔽 AI 在搜索与标签搜索结果上同样生效，仍会自动往后加载直到有匹配结果。

### 新增「排除标签」

- 分类/搜索筛选条新增「排除标签」按钮，打开管理页可以添加、删除排除项；
- 「设置 → 内容 → 排除标签」也能管理，右上角显示已排除数量；
- 在作品详情页长按标签，可直接「排除此标签」；
- 排除项会应用到首页、分类、搜索和标签搜索结果，持久保存在本地；
- 说明：列表 HTML 只有标题，没有逐条作品标签，因此排除按标题中的标签/关键词匹配，不会为每个作品额外发详情请求。
