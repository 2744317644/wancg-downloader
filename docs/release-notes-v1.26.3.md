## UI 修复

### 底部 TabBar 遮挡内容

- iOS 26 浮动 TabBar 会盖住最后一行内容（详情页推荐、设置页底部说明、文件/收藏最后一行、首页單行本卡片）；
- 给首页、收藏、下载、文件、设置、详情、分类、历史页面的滚动内容统一增加底部 76pt 内容 inset；
- 现在滑到底时最后一行可以完整露出在 TabBar 上方。

### 日期统一中文格式

- 下载页最近记录、文件列表、历史记录之前显示 `Nov 13, 2026 at 1:18` 之类英文日期；
- 统一使用 `zh_Hans_CN` 格式，例如 `2026年11月13日 01:18`，与中文界面保持一致；
- 根视图同时固定中文 Locale，相对时间也显示中文。

### 详情页标题布局

- 标题移到封面正上方，使用整行宽度，最多 3 行；
- 复制按钮固定在标题右侧，不再挤压标题；
- 封面和分类/页数/收藏/作者/日期信息仍保持在下方。

### 下载记录区分 ZIP / PDF

- 最近下载的元信息增加类型：`PDF · 27.6 MB · 2026年11月13日 01:18`；
- 同名但类型不同的 ZIP/PDF 记录不再看起来像重复下载。

### 封面加载占位

- 封面加载中显示小型 `ProgressView`，加载失败才显示图片占位图标，不再一开始就是灰色空白方块。

### 版本

- **1.26.3**（build 276）；
- GitHub Actions 构建 IPA。
