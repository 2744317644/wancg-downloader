## Windows WinUI 3 客户端 v1.0.3

### 安装版

- 新增 **Inno Setup 安装程序**：`WnacgDownloader-Setup-1.0.3.exe`
  - 按用户安装到 `%LOCALAPPDATA%\Programs\wnacg`，不需要管理员权限；
  - 创建开始菜单快捷方式，可选桌面图标；
  - 安装程序、exe、开始菜单快捷方式统一使用 **iOS 版 App 图标**（由 iOS `AppIcon` 1024px 生成多尺寸 `.ico`）；
  - 在「设置 → 应用」中可卸载。
- 同时保留便携版 zip。

### 漫画预览重做

- 单页 / 双页阅读模式（默认双页）；
- 页面自动缩放以完整显示一整页，不再一次看不完；
- 点击页面左/右半区、或底部「上一页 / 下一页」切页；
- 右上角切换「单页模式 / 双页模式」；
- 图片按需加载，缓存最近 10 页并预取相邻页；
- 双页模式按漫画阅读顺序：左页为后一页、右页为前一页。

### PDF

- 沿用 1.0.2 的固定页宽排版（横竖页宽度一致），并嵌入 PDF 开关；
- 说明：PDF 文件本身页面是铺满的，外部阅读器里页间的黑缝是阅读器的分页背景，不属于 PDF 内容；iOS App 内已关闭分页间隙。

### 运行要求

- Windows 10 1809+ / Windows 11，x64；
- 安装包未签名，SmartScreen 首次运行请选「更多信息」→「仍要运行」。
