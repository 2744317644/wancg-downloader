## Windows WinUI 3 客户端 v1.0.4

### 书签全选修复

- 修复导入书签后点「全选」不能可靠选中全部作品的问题；
- 不再依赖虚拟列表的 `ListView.SelectAll()`，改为逐项加入选中集合；
- 「全选 / 取消全选」会切换按钮文字，并在状态栏显示「共 N 个作品，已选 M 个」；
- 可直接点「下载选中」或「下载全部」（无需先勾选）。

### 导入数量提示

- 导入书签文件后会显示原始链接数、去重后作品数和重复数；
- 当前 Safari 书签文件实际为：**371 条作品链接 + 1 个文件夹（共 372 个 `<DT>` 节点）**；
- 去重后为 **367 个唯一作品**（4 个 aid 重复：336842、382051、383877、398039）。

### 安装版

- 安装包：`WnacgDownloader-Setup-1.0.4.exe`
- 按用户安装，开始菜单/桌面图标，卸载；图标与 iOS 版一致。

> 本 Release 不包含截图。
