## 标题可部分选择复制 + 长按标签复制

### 标题支持选择一部分复制

之前标题上的 `.contextMenu`（复制标题）会抢走长按手势，导致系统文本选择无法启动。现在：

- 移除标题 Text 上的 contextMenu，保留 `.textSelection(.enabled)`；
- 长按标题即可进入系统选择模式，拖动选择任意一部分并复制；
- 右侧「复制标题」按钮仍可一键复制完整标题。

### 长按标签菜单

- 作品详情页长按任意标签，菜单新增：
  - **复制标签**：写入剪贴板，并显示「已复制：标签名」胶囊提示；
  - **排除此标签**：原功能保留。
- 标签搜索、排除标签逻辑不变。

- **1.26.1**（build 274）；
- iOS 26.2 全流程 UI 测试通过。
