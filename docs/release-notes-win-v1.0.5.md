## Windows WinUI 3 客户端 v1.0.5

### 书签页布局修复

- 书签列表提前到页面顶部区域，导入后不用再滚过整页才能看到作品；
- 缩小列表高度，把「下载选中 / 下载全部」和「下载队列」放到更靠上的位置；
- 粘贴链接改为默认收起的「粘贴链接（可选）」，减少首屏占用。

### 书签下载队列

- 批量下载时新增「下载队列」区域，每一部作品显示：
  - 解析后的标题；
  - 等待中 / 下载进度（已下载页数、字节数）/ 完成文件夹 / 失败原因；
  - 「打开文件夹」和「取消」按钮；
- 队列最多保留最近 30 条，避免 367 部作品把界面撑爆；
- 停止批量下载时保留已完成/失败的队列记录。

### 窗口最小尺寸

- 通过 Win32 `WM_GETMINMAXINFO` 限制窗口最小尺寸（1100×700），防止窗口被拖得过窄导致导航栏和卡片内容被裁切；
- 窗口启动时按需恢复合适的初始尺寸。

### 安装版

- `WnacgDownloader-Setup-1.0.5.exe`
- 按用户安装，开始菜单/桌面图标，卸载；图标与 iOS 版一致。
