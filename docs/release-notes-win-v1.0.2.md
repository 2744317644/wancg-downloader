## Windows WinUI 3 客户端 v1.0.2

修复 PDF 横竖页排版，与 iOS 版保持一致。

### 变化

- 之前 PDF 每页的 MediaBox 直接按图片像素和 144 DPI 计算，横版页和竖版页的**宽度不同**，阅读器里会看到横版页更宽、竖版页更窄；
- 现在和 iOS 版一样：**所有页面统一 595pt 宽**，页高 = 图片高 × (595 / 图片宽)：
  - 竖图 → 高页（A4 比例附近）；
  - 横图 → 同宽度、较矮的页面；
  - 混排时所有页在阅读器中宽度一致。
- 仅改变页面尺寸计算，JPEG 仍以 `DCTDecode` 原样嵌入，不重新编码。

### 验证

- 生成一张 800×1200 竖图和一张 1600×900 横图的测试 PDF：
  - 两页宽度均为 793.33 px（`Windows.Data.Pdf` 按 96 DPI 报告，即 595pt）；
  - 页高分别为 1190px 和 446.25px；
- 用 `Windows.Data.Pdf` 实际渲染确认内容正常。
- 版本 1.0.2；仍是免安装 self-contained x64。

下载后解压运行 `WnacgDownloader.exe` 即可；首次运行 SmartScreen 选「更多信息」→「仍要运行」。
